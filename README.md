**DNA Sequence Analyser**

A beginner Python project that analyses DNA sequences.

Features:
Calculates DNA sequence length
Calculates GC content
Calculates AT content
Calculates the percentage of each nucleotide (A, T, C, G)
Counts the number of each nucleotide
Checks whether the entered sequence contains only valid DNA bases

For example:
Input: ATGCGTACCGTA

The program returns the sequence length, GC and AT percentages, individual base percentages, and nucleotide counts.
